# SmartMed

> ### Projeto idealizado na matéria de Programação I, com a finalidade<br>de lapidar os conhecimentos envolvendo Java e SpringBoot.

Sistema genérico voltado para gerenciamento dos dados envolvendo as características  
observadas nos processos das clínicas, possibilitando manejo de informações como consultas,  
médicos, pacientes e outros.
